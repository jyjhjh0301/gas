# 가스사용시설안전관리자 문제은행

첨부된 기출복원 자료 200문제를 챕터별로 풀 수 있는 정적 웹사이트입니다.

- 순서대로 풀기: 선택한 챕터 또는 소챕터 범위에서 순서대로 풉니다.
- 선택 범위 랜덤: 선택한 범위 안에서 문제 순서를 무작위로 섞습니다. 챕터를 누른 뒤 이 버튼을 누르면 챕터별 랜덤입니다.
- 전체 랜덤: 범위를 전체 200문제로 바꾸고 무작위 순서로 풉니다.
- 오답만 풀기: 틀린 문제를 다시 풉니다.
- 모의고사: 세트마다 법규 5문제, 가스개론 5문제, 사고분석 3문제, 가스설비 7문제를 중복 없이 뽑습니다. 문제당 3점, 총 20문제 60점 만점입니다. 만든 세트는 세트 선택 메뉴에서 다시 열 수 있고 새 세트를 추가로 만들 수 있습니다. 답안 저장 후 이동하거나 문제 이동 메뉴를 사용할 수 있습니다. 제출 전까지 정답은 표시되지 않습니다. 제출하면 60점 만점 점수와 문항별 결과가 나오고, 해설은 각 문항의 `해설 보기`를 눌러야 나옵니다. 제출 전 미응답 문항은 제출할 때 확인합니다.

풀이 기록 및 모의고사 세트와 진행 중인 답안은 해당 브라우저에 저장됩니다. 일반 학습은 `정답 확인` 뒤에도 `해설 보기`를 눌러야 해설이 나옵니다.

## GitHub Pages에 올리기

1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더의 **`index.html`, `style.css`, `app.js`, `가스사용시설안전관리자_문제은행.json`** 네 파일을 저장소 최상위에 올립니다. `README.md`도 함께 올려도 됩니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, 브랜치 **main**, 폴더 **/(root)**를 선택하고 저장합니다.
4. 표시되는 Pages 주소로 접속합니다. 배포 직후에는 반영까지 잠시 걸릴 수 있습니다.

이미 이전 버전을 올렸다면 같은 이름의 파일 중 `index.html`, `style.css`, `app.js`만 새 버전으로 교체해도 됩니다. 문제은행 JSON은 이전과 동일합니다.

컴퓨터에서 확인하려면 이 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`을 엽니다. HTML 파일을 직접 더블클릭하면 브라우저가 JSON 읽기를 막을 수 있습니다.

원본의 법령 수치, 정답, 해설은 최신 법령 기준으로 별도 검증되지 않았습니다.
