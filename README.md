# 가스사용시설안전관리자 문제은행 · v1.2

영어 문제은행과 같은 상단 모드 전환, 과목 필터, 상태 표시줄, 회차형 모의고사 화면으로 구성했습니다.

## 연습

- 왼쪽에서 출제 과목을 여러 개 선택하고 `선택 과목 랜덤` 또는 상단 `혼합 연습`을 누르면 섞어 풀 수 있습니다.
- `전체 200문제 랜덤`은 과목 선택과 관계없이 전체 문제를 섞습니다. 세부 챕터를 눌러 범위를 좁힐 수도 있습니다.
- 보기를 누르면 바로 채점됩니다. 해설은 `해설 보기`를 누를 때만 나옵니다.
- `1–4` 보기 선택, `N` 다음 문제, `A` 해설 열기 단축키를 지원합니다.

## 시험 모드

상단 `시험 모드`를 누르면 **7회분 모의고사 세트**가 만들어집니다. 각 회차는 법규 5, 가스개론 5, 사고분석 3, 가스설비 7문제이며, 문제당 3점, 60점 만점입니다. 각 과목의 원본 문항을 섞어 회차 사이에 같은 문제가 나오지 않도록 배정합니다. 가스설비가 50문제이므로 7회(49문제 배정)까지 중복 없이 구성할 수 있습니다.

회차 카드를 눌러 응시하거나 성적을 다시 볼 수 있습니다. 답을 고르면 자동 저장되며 제출 전에는 정답이 표시되지 않습니다. 제출 후 문항별 결과가 표시되고, 해설은 문항마다 별도로 열 수 있습니다. `전체 세트 다시 섞기`는 7회 문제 배치와 해당 성적을 모두 지우므로 확인창이 뜹니다.

풀이 기록과 회차별 답안은 이 브라우저에 저장됩니다. 예전 버전의 일반 학습 기록은 유지되지만, 개별 생성 방식의 이전 모의고사는 새 7회 구성에 맞지 않아 새로 생성됩니다.

## GitHub Pages

ZIP을 풀고 `index.html`, `style.css`, `app.js`, `가스사용시설안전관리자_문제은행.json`을 저장소 최상위에 업로드하세요. 기존 저장소라면 앞의 HTML·CSS·JS 파일만 교체하면 됩니다. 저장소 **Settings → Pages**에서 `main` 브랜치와 `/(root)` 폴더를 선택합니다.

로컬 확인은 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`으로 접속합니다. 원본의 법령 수치, 정답, 해설은 최신 기준으로 별도 검증되지 않았습니다.

> 이 사이트는 출제 경향 참고용입니다. 실제 시험이 이 200문제에서 문제은행 방식으로 출제된다는 뜻이 아니며, 원본의 법령 수치·정답·해설은 최신 기준으로 별도 검증되지 않았습니다.
